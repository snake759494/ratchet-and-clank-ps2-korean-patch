# 글꼴 출처

- 게임 글꼴(256×256 PSMT8, 16px 칸)을 256×1024 로 확장하고 한글 880자를 추가: NanumSquare Neo cBd(Bold) 14px, 4배 확대 렌더 후 축소해 원본 팔레트의 회색 알파 단계로 변환 (`tools/build_font.py`).
- 컷신 타이틀 카드 17장, 타이틀 화면 "START 버튼": NanumSquare Neo dEb(ExtraBold), 원본 팔레트의 알파로 양자화 (`tools/cards.py`, `tools/hudimg.py`).
