# 기술 설명

## 디스크 구조
- ISO 파일시스템에는 `SYSTEM.CNF`, `SCPS_150.37`(ELF), `IOPRP243.IMG` 만 있고, 게임 데이터는 섹터 1500의 목차(ToC, `(LBA, 섹터 수)` 쌍)로 참조되는 원시 영역에 있습니다.
- 레벨 19개는 각자 헤더(레벨 LBA)에 하위 파일 4개의 `(LBA, 크기)` 를 절대값으로 가집니다. 하위 파일 1이 레벨 텍스트 표입니다.
- 압축: `WAD` 헤더(0x10바이트) + LZO1X 변형. 압축 데이터는 0x2000 블록 단위이며, 블록 끝은 `12 00 00` + 0xEE 패딩, 블록 시작은 `11 00 00`, 긴 리터럴은 `11 00 00`(무동작)으로 나눕니다 (`tools/wad.py`, `tools/wadc.py`).

## 텍스트
- 전역 텍스트: ToC 677번(비압축, 1,741항목). 레벨 텍스트: 레벨별 하위 파일 1(WAD, 약 1,470항목).
  표는 `(문자열 오프셋, ID, -1, 0)` 16바이트 엔트리. 번역문은 원래 블록 크기 안에 다시 배치합니다.
- 컷신 자막: 장면 WAD 1,644개. 헤더+4가 자막 블록을 가리키며 엔트리는 `(시작 프레임, 끝 프레임, 언어별 오프셋 5개)`, `FFFFFFFF` 로 끝납니다. 일본어 슬롯에 한국어를 넣고 다른 언어 슬롯은 빈 문자열 하나를 공유하게 해 원래 크기 안에 맞춥니다.
- 일본어판 문자 코드: 1바이트 가나(0x80~0xFF), 0xBD/0xBE 는 탁점·반탁점(앞 글자에 겹침), 0x01 줄바꿈, 0x08~0x0F 색, 0x10~0x19 버튼 아이콘.

## 한글 출력
- 인코딩: 2바이트(리드 0xF0~0xFF, 트레일 0xA8~0xEF 중 0xBD/0xBE 제외) + 빈도 상위 40음절은 1바이트(0x80~0xA7). 1바이트 코드는 용량(블록 크기 고정)을 맞추려고 도입했습니다.
- 글리프 표(256×4바이트 `u, v, y오프셋, 폭`)에서 리드/트레일 바이트의 폭을 7로 두어 원래 폭 계산·줄바꿈 코드를 그대로 씁니다(합 14px). 표식으로 v=0xFF(리드)/0xFE(트레일).
- 글리프 사각형 출력 함수(정수·실수 좌표 2종) 입구에 훅: 리드는 값만 보관, 트레일에서 두 바이트로 한글 칸을 계산해 x−7 위치에 그립니다.
- 폰트 텍스처 요청 함수 훅: 슬롯 1(폰트)일 때 기준 포인터와 슬롯 필드를 잠시 바꿔 256×1024 확장 폰트(0xA5000)를 쓰게 합니다. UV 14비트 한계로 한글 영역은 47행까지 사용합니다.
- ELF에 새 PT_LOAD 세그먼트(0xA0000~, 훅 코드 + 폰트)를 추가했습니다. ELF가 커져 `IOPRP243.IMG` 를 섹터 1369로 옮겼습니다.
- 레벨 코드 오버레이: 0x165580 이후(.data·레벨 코드)는 레벨마다 디스크의 비압축 사본으로 바뀝니다. 사본 20개를 패턴으로 찾아 각각의 실행 주소(내부 `jal` 대상에서 역산), 슬롯 표, 기준 포인터를 읽어 오버레이별 전용 훅을 생성합니다 (`tools/overlays.py`, `tools/elfpatch.py`).

## 자막 기본 켜기
- 자막 설정 바이트(0x15EF40)는 타이틀 진입 때 0으로 초기화됩니다. 판정 분기(`lbu ...; beql v0,zero`)를 `bnel` 로 바꿔 0일 때 자막을 그리게 하고, 옵션 메뉴 항목의 끔/켬 라벨 ID를 맞바꿔 표시를 일치시켰습니다(ELF + 오버레이 20개).

## 이미지
- 컷신 타이틀 카드: 인트로 장면 파일의 PIF2 이미지(512×64 PSMT8) 17장. 배경이 불투명한 검정이고 글자 부분이 투명한 마스크라 알파를 반전해 그립니다.
- 타이틀 "START 버튼": 메뉴 레벨 HUD 텍스처 4번(256×128). RGB는 그라데이션 띠, 글자 모양은 알파에 있어 알파만 다시 그립니다.

## 동영상 자막
- 동영상 39편은 ToC 767~850번의 `(LBA, 바이트 크기)` 항목. MPEG-PS(16KB 팩), 영상 MPEG-2 512×416 30fps 프로그레시브 4Mbps(VBV 1,310,720비트, GOP 18), 음성은 private stream 1 의 SShd/SSbd PS-ADPCM 48kHz 스테레오, 인터리브 0x20바이트 (`tools/pss.py`).
- 음성을 16kHz 모노로 풀어 faster-whisper large-v3 로 받아쓴 뒤(`tools/movie_asr.py`) 직접 번역해 `movie/subs/V###.tsv`(시작초, 끝초, 자막)로 만들었습니다. 무음 구간에 생기는 받아쓰기 환각 문장은 뺐습니다.
- 자막 합성(`tools/movie_sub.py`, 간츠·블랙 패치 방식): 자막이 걸린 GOP 구간만 닫힌 GOP로 재인코딩하고, 구간 바이트가 원본 이하가 되는 가장 고운 q(실제 2~6)를 고른 뒤 남는 바이트는 0으로 채워 영상 ES 길이를 원본과 같게 맞춰 원래 PES 자리에 되돌려 씁니다. 음성 패킷과 팩 구조는 바뀌지 않습니다.
- 자막 모양: NanumSquare Neo Bold, 흰 글자 + 2px 검은 외곽선, 화면 아래 가운데, 길면 2줄.
